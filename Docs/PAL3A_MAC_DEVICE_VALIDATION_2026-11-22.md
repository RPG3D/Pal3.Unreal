# PAL3A Mac 与真机验证补充（2026-11-22）

这是 Windows 功能提交在 Mac 还原后的验证与修正记录，不替代前面的 Windows 历史记录。

## 本轮改动

- 插件：固定程序集集合激活后，`HasPendingHotReloadChanges` 不再触发焦点重载重试；显式重载清理旧队列，并且只提示一次需要重启。
- 工程：删除自由切图中强制使用相机预设 2 的特殊处理，恢复地图与脚本的默认设置。预设 2 会关闭旋转，之前因此导致镇江等室外自由切图后隐藏右摇杆；其状态也会进入存档。
- 工程：标题界面和游戏内 Menu 共用游戏名称、文本键和字体，保留原来的繁体显示；PAL3A 与英文沿用各自现有标题。
- 本地绑定：重新生成旧的 UHT 输出，解决缺少 `FUtf8String SubPathString` 而产生的重复构造函数；备份并清理旧宿主 DLL，消除旧 `UnrealSharp.Editor.dll` 与新 native 回调布局的冲突。这些是本地生成产物恢复，没有删除手写构造函数或修改引擎源码。

### 用户数据与授权位置

- Android 读取 `Download/PAL3` 与 `Download/PAL3A`，保留既有文件权限。测试前后备份并恢复用户存档，包括用户在测试间隙新建的手动槽。
- iPad 原有 PAL3 使用“下载/PAL3”；用户本轮为 PAL3A 选择了 SharpDemo 文档中的 `PAL3A-Import`，没有将其移到下载目录。两个 bookmark 分开保存，并在多次进程重启与覆盖安装后保留。
- iPad 原有七个存档逐字节恢复核对，临时测试槽已删除。没有把正式存档改到临时测试目录，也没有重置新授权。
- 早期镇江读档后的坐标变化伴随用户操作；用户确认停止操作后，冷启动与进程内加载各九次静置采样全部保持保存坐标，不将之前的变化认定为已确认存档 bug。

### 内存与边界

本轮 iPad 采样最大物理 footprint 约 1191 MiB，Android 最大 PSS 约 1075 MiB，指标不同，不作直接平台比较。混合切图、重启和驻留期间未见持续失控增长，但不能据短时回归排除长时间游玩的慢性泄漏。

出现过一次引擎 Trace 初始化的原生崩溃，发生在 CLR 与游戏加载前，详见 [启动崩溃记录](IOS_TRACE_STARTUP_CRASH_2026-11-22.md)。暂缓引擎修复，不把当前 iPad 开发包描述为已证明无启动稳定性问题。

移动 CoreCLR、Shipping/R8、Simulator、Client/Server、全地图及完整剧情通关不属于这轮通过范围。运行时切换游戏通过关闭进程后重新启动验证，没有实现同进程卸载热切换。

### 本机环境恢复

iOS 打包所用七天开发描述文件在测试中途过期，用户登录 Xcode 后已重新获取。可选 UGP 弱回调沿用此前已验证的链接参数，不修改引擎。旧 Zen Cook 项目存储失效，改用独立本地目录与 `-SkipZenStore` 生成资源。

原始构建、设备与校验记录位于 `Saved/Review/Pal3A-Mac-Fix-20261122`、`Saved/DeviceQA/PAL3A-20261122` 和 `Saved/Packaging/Pal3A-Title-20261122`。安装包、设备标识、授权 bookmark 和原版数据均未提交。
